# Background Animation

A small creative experiment built while learning the fundamentals of web development.

## About the Project

This project is a simple background animation created using **HTML, CSS, and JavaScript**.

It was one of my early experiments with front-end development, where I explored how these three technologies work together to create interactive and visually engaging web experiences.

The goal was to learn by building, experiment with animations, and understand how to bring a static webpage to life.

## Technologies Used

- **HTML5** – Structure of the webpage.
- **CSS3** – Styling, visual effects, and animations.
- **JavaScript** – Dynamic behavior and animation logic.

## What I Learned

Through this project, I got to explore:

- The fundamentals of HTML document structure.
- CSS styling and animation techniques.
- Using JavaScript to manipulate webpage elements.
- How HTML, CSS, and JavaScript work together.
- Learning through experimentation and hands-on practice.
